type: writing-rule
---

A number carries a meaning a bullet does not, an order.
Number a list only when the number does work.

Number it when the items run in a sequence, or when the reader points back to one by its number:
- Steps taken in turn
- A ranked series
- An item the reader will cite, "do 2 and 4"

Otherwise use a bullet.
A number on an unordered set is a false signal, it implies an order that is not there.

To check, renumber the list at random, if nothing is lost it should be a bullet.
